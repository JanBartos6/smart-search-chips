Support

Support Policy

Free users can report plugin issues through WordPress.org. Pro customers receive priority email support for setup, troubleshooting, licensing, and compatibility questions.

Last updated: April 2026

Free Version Support

Support for the free version is provided through the WordPress.org support forum. We monitor the forum regularly and respond to bug reports and compatibility issues.

Pro Support

Pro license holders receive priority email support at support@smartsearchchips.app. We aim to respond within 1-2 business days.

What Is Covered

  • Bug reports and troubleshooting
  • Installation and activation help
  • Configuration guidance for plugin settings
  • Compatibility issues with standard WordPress themes and plugins
  • License and billing questions

What Is Not Covered

  • Custom development or theme modifications
  • Third-party plugin conflicts requiring code changes outside Smart Search Chips
  • Server configuration or hosting issues
  • Performance optimization of your WordPress installation
