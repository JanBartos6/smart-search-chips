A free plugin that is genuinely useful

Core search, chips, indexing, and troubleshooting are not paywalled.

A search box you can trust

  • Add the search block or [sschp_search] anywhere you need a reliable search experience.
  • The guaranteed UI uses the plugin endpoint, so it does not depend on theme AJAX.
  • Compatible theme searches can be enhanced safely when you want to keep the existing layout.
  • Existing [ssc_search] embeds keep working through the legacy alias.

Built for real catalogs

  • The local index keeps larger catalogs responsive once it is ready.
  • You can rebuild, pause, resume, clear, or process one batch from settings.
  • If the index is not ready, search keeps working through Relevanssi or WP_Query fallback.

Chips from product language

  • Use the built-in Search Chips Tags field for posts, pages, and products.
  • WooCommerce helper tags can pull from attributes, categories, and product tags.
  • SKU chips stay optional so unique part numbers do not flood the interface.
  • Diagnostics explain missing product post types, helper tags, and empty chip sets.
